# ☕ Café Sales Performance Dashboard – Power BI

📌 Project Overview

This project presents an interactive Café Sales Performance Dashboard developed using Microsoft Power BI to analyze sales performance, product performance, customer purchasing patterns, payment methods, and sales channels.
The dashboard provides both a high-level overview of café performance and a more detailed analysis of revenue, quantity sold, transactions, and average order value across different dimensions.

🎯 Project Objective

The objective of this project was to transform café sales data into an interactive dashboard that provides insights into:
- Overall revenue and sales performance
- Product performance
- Monthly revenue and transaction trends
- Payment method performance
- Sales channel performance
- Customer purchasing patterns
- Average order value
  
🛠️ Tools Used

- Microsoft Power BI
- Power Query – Data cleaning and transformation
- DAX – Measures and calculations
- Data Visualization – Interactive dashboard development
  
📊 Dashboard Pages

1. Sales Overview
The Sales Overview page provides a high-level summary of café sales performance.
Key KPIs
- Revenue: $13.22K
- Quantity Sold: 13.4K
- Transactions: 4.4K
- Total Amount Spent: $40K
- Average Order Value: $3.02
  
Visualizations

The page includes:
- Monthly Revenue Trend
- Revenue by Product
- Revenue by Payment Method
- Revenue by Sales Channel
- Key Insights section
- Interactive filters for Product, Payment Method, and Sales Channel
  
Key Insights

- Salad generated the highest revenue, with approximately $3,116.
- July recorded the highest monthly revenue, reaching approximately $1,461.
- Revenue remained relatively stable across most store locations.
  
2. Sales Analysis
  
The Sales Analysis page provides a more detailed breakdown of sales activity.
It analyzes:
- Quantity Sold by Product
- Quantity Sold by Payment Method
- Transactions by Product
- Monthly Transactions Trend
- Average Order Value Trend
- Transactions by Payment Method
This page makes it easier to compare product demand, transaction activity, payment methods, and changes in average order value throughout the year.

🔍 Key Findings

The analysis showed that:
- Salad was the highest-revenue product, generating approximately $3.1K.
- July had the highest monthly revenue, at approximately $1.46K.
- In-store sales generated slightly higher revenue than takeaway sales, with approximately $6.7K compared with $6.6K.
- Cash and credit card payments accounted for similar transaction volumes, while digital wallet transactions were slightly lower.
- Monthly transactions reached their highest point in July, at approximately 480 transactions.
- Average Order Value remained relatively stable throughout the year, generally around $3.00.
